**Movie Recommendation System**

This project provides personalized movie recommendations using Correlation Coefficient, Cosine Similarity, and KNN. It is built with Python, Pandas, Scikit-learn, and Streamlit for an interactive UI.

*Features:-*

Hybrid recommendation system combining multiple algorithms
Streamlit web app for easy user interaction
Movie dataset-based recommendations

*Usage:-*

Enter a movie title to get recommendations.
Modify movies.csv and ratings.csv to use a different dataset.

*Technologies Used:-*

Python, Pandas, Scikit-learn, Streamlit
